# Entropretty

Beautiful visualizations of entropy.

## Overview

Entropretty is a collection of tools and libraries for creating deterministic, visually distinct patterns from arbitrary data. Each algorithm transforms raw bytes into unique visual fingerprints — useful for identity verification, key visualization, and generative art.
